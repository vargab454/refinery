# Commands
- ./gradlew :refinery-opencypher:generateXtextLanguage
  - Generates the necessary files from the xtext language
- ./gradlew :refinery-opencypher:compileJava
  - Compile java files
- ./gradlew :refinery-opencypher:runRefineryTransformer
  - Runs the actual transformer that makes refinery compatible code from the
    given xtext syntax
